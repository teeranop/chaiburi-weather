# Chaiburi Weather

หน้าเว็บรวมสภาพอากาศ ฝน น้ำท่วม และเตือนภัย อ.ชัยบุรี จ.สุราษฎร์ธานี

เปิดใช้งาน: https://teeranop.github.io/chaiburi-weather/

## แหล่งข้อมูล

| ส่วนในหน้าเว็บ | แหล่งข้อมูล | ดึงจาก |
|---|---|---|
| สรุประดับสถานการณ์ | คำนวณจากทุกแหล่งด้านล่าง | GitHub Actions → `data/summary.json` |
| สภาพอากาศปัจจุบัน | กรมอุตุฯ: ค่าวัดสถานีใกล้ที่สุด (พระแสง สอท.) + สภาพท้องฟ้าจาก NWP รายชั่วโมง | GitHub Actions → `data/tmd.json` (`current`, `hourly`) |
| พยากรณ์ 12 ชม. / 7 วัน | กรมอุตุฯ NWP ที่พิกัดที่ว่าการอำเภอ | GitHub Actions → `data/tmd.json` (`hourly`, `forecast`) |
| ฝนสะสมย้อนหลัง 30 วัน | ThaiWater สถานี อบต.ชัยบุรี (`rain_monthly_graph`, `rain_24h_graph`) | เบราว์เซอร์ (สด) |
| จุดวัดน้ำฝนจริง, เขื่อน/อ่างเก็บน้ำ | ThaiWater (สสน.) | เบราว์เซอร์ (สด) |
| สถานีตรวจอากาศใกล้เคียง | กรมอุตุนิยมวิทยา (data.tmd.go.th) | GitHub Actions → `data/tmd.json` |
| พื้นที่น้ำท่วมจากดาวเทียม 1/3/7/30 วัน, น้ำท่วมซ้ำซาก | GISTDA Disaster Platform | GitHub Actions → `data/flood*.json` |

ข้อมูลที่ต้องใช้ API key (GISTDA, กรมอุตุฯ) ดึงฝั่ง GitHub Actions ด้วย secrets
หน้าเว็บอ่านเฉพาะไฟล์ JSON ที่ประมวลผลแล้ว จึงไม่มี key อยู่ในโค้ดหน้าเว็บ

## ติดตั้ง (ครั้งเดียว)

1. **เปลี่ยนวิธี deploy ของ Pages**
   Settings → Pages → Build and deployment → Source = **GitHub Actions**

2. **เพิ่ม secrets** — Settings → Secrets and variables → Actions → New repository secret

   | Secret | จำเป็น | ได้จาก |
   |---|---|---|
   | `GISTDA_API_KEY` | สำหรับส่วนน้ำท่วม | https://api-gateway.gistda.or.th → API Keys → สร้าง API Key |
   | `TMD_UID`, `TMD_UKEY` | ไม่บังคับ (ไม่ตั้ง = ใช้ demo/demokey) | ลงทะเบียนที่ https://data.tmd.go.th/api/index1.php |
   | `TMD_NWP_TOKEN` | สำหรับสภาพท้องฟ้าปัจจุบัน + พยากรณ์รายชั่วโมง/7 วัน | ลงทะเบียน NWP API ที่ data.tmd.go.th/nwpapi → Create New Token |
   | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | ถ้าต้องการแจ้งเตือนทาง Telegram | @BotFather |
   | `MOPH_CLIENT_ID`, `MOPH_SECRET` | ถ้าต้องการแจ้งเตือนทาง LINE (LINE OA หมอพร้อม) | ค่า Client_ID และ Secret จาก CMS MOPH Notify → เมนูหน่วยบริการ/กลุ่ม (กดไอคอนกุญแจที่ช่อง API Key) — ต้องเพิ่ม LINE "หมอพร้อม" เข้ากลุ่ม และแอดมินอนุมัติกลุ่มใน CMS ก่อน |

3. **สั่งรันครั้งแรก** — Actions → "อัปเดตข้อมูลและเผยแพร่หน้าเว็บ" → Run workflow

## รันในเครื่อง

คัดลอก `.env.example` เป็น `.env` แล้วใส่ key (ไฟล์ `.env` อยู่ใน `.gitignore` จะไม่ถูก commit) จากนั้นรัน

```bash
python scripts/fetch_data.py --no-telegram
```

`--no-telegram` = ไม่ส่งแจ้งเตือน (ทั้ง Telegram และ LINE) · ผลลัพธ์อยู่ใน `data/` · ค่าที่ตั้งใน environment จะใช้ก่อนค่าใน `.env`

## รอบการทำงาน

- ทุกชั่วโมง (นาทีที่ 17): ดึงข้อมูลใหม่และ deploy หน้าเว็บ
- 06:53 น. ทุกวัน: ส่งรายงานสรุปประจำวันทาง Telegram และ LINE หมอพร้อม (ช่องทางที่ตั้ง secrets ไว้)
- ส่งแจ้งเตือนทันทีเมื่อระดับสถานการณ์เปลี่ยน
- น้ำท่วมซ้ำซาก (flood-freq) ดึงใหม่ทุก 7 วัน เพราะเป็นข้อมูลสถิติ

## เกณฑ์ระดับสถานการณ์

| ระดับ | เงื่อนไข (เข้าข้อใดข้อหนึ่ง) |
|---|---|
| 🟢 ปกติ | ไม่เข้าเงื่อนไขด้านล่าง |
| 🟡 เฝ้าระวัง | ฝน 24 ชม. ≥ 35.1 มม. · ฝนรายชั่วโมง ≥ 30 มม. · ฝนสะสม 7 วัน ≥ 200 มม. (ดินอิ่มน้ำ) · ระดับน้ำ ≥ 80% ของตลิ่ง · กรมอุตุฯ คาดฝน 24 ชม. ข้างหน้า ≥ 90.1 มม. (หรือ ≥ 35.1 มม. ขณะดินอิ่มน้ำ) · มีน้ำท่วมในอำเภอรอบ 30 วัน |
| 🟠 เตือนภัย | ฝน 24 ชม. ≥ 90.1 มม. · ฝนหนัก (≥ 35.1 มม.) ขณะดินอิ่มน้ำ · ระดับน้ำ ≥ 100% ของตลิ่ง (ล้นตลิ่ง) · ดาวเทียมพบน้ำท่วมในอำเภอรอบ 1–7 วัน |
| 🔴 วิกฤต | ฝน 24 ชม. ≥ 150 มม. · น้ำท่วมในอำเภอรอบ 1–3 วัน ≥ 1,000 ไร่ · น้ำท่วมรอบ 1–3 วันร่วมกับฝนหนัก |

ปรับเกณฑ์ได้ที่ค่าคงที่ `RAIN7_SATURATED`, `RAIN_1H_INTENSE`, `WL_WATCH`, `WL_WARN` และฟังก์ชัน `assess()` ใน `scripts/fetch_data.py`
ค่าฝนใช้ค่าสูงสุดของสถานี ThaiWater ในอำเภอ (ถ้าไม่มีใช้รัศมี 40 กม.) และสถานีกรมอุตุฯ ในรัศมี 60 กม.
ฝนสะสมใช้สถานี ThaiWater อบต.ชัยบุรี · ระดับน้ำใช้สถานีโทรมาตร ThaiWater ใน อ.ชัยบุรี/พระแสง/เขาพนม (`WL_AMPHOE`, ค่าที่เก่ากว่า 24 ชม. ไม่นำมาใช้)
อ.เขาพนม จ.กระบี่ (ติดต่อชัยบุรี น้ำไหลมาชัยบุรี): รายงานฝนสูงสุดและ % ความจุอ่างเก็บน้ำ — ฝน 24 ชม. ≥ 90.1 มม. หรืออ่างฯ ≥ 100% → 🟡 เฝ้าระวัง

## รันบนเครื่องตัวเอง

```bash
export GISTDA_API_KEY=...        # ตัวอื่นตามตารางด้านบน
python3 scripts/fetch_data.py --out data --no-telegram
python3 -m http.server 8000      # เปิด http://localhost:8000
```

ใช้ไลบรารีมาตรฐานของ Python 3.9+ เท่านั้น ไม่ต้อง `pip install`

ถ้า GitHub Actions เรียก API ของ GISTDA หรือกรมอุตุฯ ไม่ได้ (เช่น ถูกจำกัดการเข้าถึงจากต่างประเทศ)
ให้ใช้ self-hosted runner ในประเทศ หรือรันสคริปต์ด้วย cron บนเซิร์ฟเวอร์ของหน่วยงานแทน

## ข้อจำกัดของข้อมูล

- น้ำท่วมจาก GISTDA แปลจากภาพดาวเทียม ปรับปรุงราววันละ 1–2 ครั้ง ไม่ใช่ข้อมูลเรียลไทม์และไม่มีความลึกน้ำ
  ถ้าไม่มีภาพใหม่ผ่านพื้นที่ จะไม่พบน้ำท่วมแม้มีน้ำท่วมจริง
- ประชากร/อาคารในพื้นที่ท่วมนับต่อเซลล์ H3 ครั้งเดียว
- ระดับสถานการณ์เป็นการคำนวณอัตโนมัติเพื่อประกอบการตัดสินใจ ไม่ใช่ประกาศทางราชการ
